1. Como Surgiu o HTML

O HTML foi criado por Tim Berners-Lee na década de 1990. A ideia original era permitir que cientistas compartilhassem documentos de forma simples e organizada.

Naquela época, a web era muito simples. Não existiam layouts complexos nem estilos avançados como vemos hoje. O objetivo era apenas estruturar o conhecimento usando o padrão HTML.

"A força da Web está na sua universalidade. O acesso de todos, independentemente da deficiência, é um aspecto essencial." — Tim Berners-Lee

2. O que são Tags

As tags são os elementos fundamentais do HTML. Elas servem para indicar ao navegador como o conteúdo deve ser exibido na tela.

Estrutura das Tags

A maioria das tags possui abertura e fechamento, como a tag de parágrafo <p>. Veja alguns recursos de formatação de texto:

  • Texto em negrito com strong para destacar pontos importantes.
  • Texto em itálico para termos em outros idiomas ou texto sublinhado para dar ênfase visual.
  • Podemos usar a tag mark para destacar uma palavra importante no meio da frase.
  • Podemos incluir notações científicas como H2O (usando sub) ou fórmulas como X2 (usando sup).
  • Também existe a tag font com cor estilizada para alterar visualmente um elemento.

3. O que são Links

Os links (ou hiperlinks) são a base da navegação na Web. Eles conectam diferentes páginas entre si ou diferentes partes de uma mesma página através de âncoras.

Tipos de Links

  1. Links Internos (Âncoras): Usados para navegar na própria página (como os botões de voltar ao topo).
  2. Links Externos: Apontam para outros websites na internet.

Resumo Rápido

Importante lembrar:
Sem links, a web não seria uma rede interconectada!
